# FerNotify v1.x (Legacy)

::: callout warning "Versión legacy"
Estás viendo la documentación de **v1.x**, que depende de anime.js y Boxicons. Se recomienda migrar a **v2.0.0** que elimina todas las dependencias externas.

[Ver documentación de v2.0.0 →](/)
:::

## Instalación (v1.x)

v1.x requería cargar anime.js y Boxicons manualmente:

```html
<head>
  <!-- Boxicons (requerido) -->
  <link href="https://unpkg.com/boxicons@2.1.4/css/boxicons.min.css" rel="stylesheet">
</head>
<body>
  <!-- anime.js (requerido) -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/animejs/3.2.1/anime.min.js"></script>
  <!-- FerNotify v1 -->
  <script src="https://cdn.jsdelivr.net/gh/Fernandocabal/fernotify@1.2.12/dist/notification-system.js"></script>
</body>
```

## API

La API de v1.x es idéntica a v2.0.0. Consulta la [guía de migración](/migration) para actualizar.
